## Overview

`XlsxParser` reads workbook bytes from an `ArrayBuffer` and returns a parsed workbook model that can be rendered as Excel-like HTML.

Use it when you need to:

- inspect workbook content in the browser
- render one sheet at a time for tabbed interfaces
- render the entire workbook as a single HTML document
- experiment with parser options such as `styles`, `drawings`, and `skipHiddenRows`

The examples below use the real package build generated from this repository and an embedded sample workbook that also works when the docs are published to GitHub Pages.

## Implementation

### Parse a workbook

<Source
  language="ts"
  dark
  code={`import { XlsxParser } from "xlsx-to-js";

const parser = new XlsxParser();
const workbook = await parser.readFile(fileArrayBuffer, {
  dense: true,
  styles: true,
  drawings: true,
  skipHiddenRows: true,
});`}
/>

### Render a single sheet

<Source
  language="ts"
  dark
  code={`const parser = new XlsxParser();
const workbook = await parser.readFile(fileArrayBuffer, {
  dense: true,
  styles: true,
  drawings: true,
  skipHiddenRows: true,
});

const html = parser.toHTMLSheet(workbook, 0);
document.getElementById("sheet-view")!.innerHTML = html;`}
/>

### Render the full workbook

<Source
  language="ts"
  dark
  code={`const parser = new XlsxParser();
const workbook = await parser.readFile(fileArrayBuffer, {
  dense: true,
  styles: true,
  drawings: true,
  skipHiddenRows: true,
});

const html = parser.toHTML(workbook);
document.getElementById("workbook-root")!.innerHTML = html;`}
/>
